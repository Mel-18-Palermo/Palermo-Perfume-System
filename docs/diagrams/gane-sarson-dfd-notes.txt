Palermo DFD notation correction — Gane & Sarson

Purpose
-------
The Final SRS DFD set must use Gane & Sarson notation consistently.

Notation applied
----------------
- External entity: rectangle.
- Process: rounded rectangle carrying the process number and verb-oriented name.
- Data store: DFD datastore/open-store symbol.
- Data flow: labelled directional arrow.

Files corrected
---------------
- docs/diagrams/dfd-level-0.mmd
- docs/diagrams/dfd-level-1.mmd
- docs/diagrams/dfd-level-2-commerce.mmd

Logical scope
-------------
The business meaning and approved data flows are preserved. This correction changes
notation and tightens DFD semantics rather than introducing new requirements.

One semantic cleanup is included:
- the delivery simulator is no longer drawn as a plain internal rectangle.
- Level 1 treats delivery simulation as behaviour contained within Process 4.0.
- Level 2 exposes it as internal Process 4.8 "Simulate Delivery Status", keeping it
  inside Palermo and preserving D-046/D-047.

Mermaid compatibility
---------------------
These files use Mermaid's expanded flowchart shape syntax (`shape: rounded`,
`shape: rect`, `shape: datastore`), available in Mermaid v11.3.0+.
If a downstream renderer uses an older Mermaid version, render/export the final
report diagrams with a Mermaid 11.3+ renderer rather than replacing the notation
with circles or database cylinders.

Reference distinction
---------------------
Gane & Sarson applies to the DFD set only. The UML-style use-case, sequence, ERD and
class diagrams keep their own appropriate notation.
