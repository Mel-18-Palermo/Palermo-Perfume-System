Palermo Final SRS System Architecture — report simplification

This file replaces the previous detailed architecture diagram for the main SRS report.

Report intent:
- communicate the high-level system boundary and major dependencies at a glance;
- keep detailed module decomposition in prose / supporting technical artefacts;
- avoid unreadable nested architecture in the submitted report.

The diagram preserves the locked architecture:
- Next.js + TypeScript modular monolith;
- Prisma data access;
- Supabase PostgreSQL;
- Email, Stripe and AI as external services behind integration adapters;
- delivery simulator remains internal to Palermo.

The diagram intentionally does NOT show every domain module, route handler, UI surface,
provider-specific SDK or internal layer because those details are unnecessary in Section 4.1.
