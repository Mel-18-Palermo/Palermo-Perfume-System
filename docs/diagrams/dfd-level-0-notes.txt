Palermo Context Diagram / DFD Level 0 — Notes

Purpose
-------
This is the Final SRS context diagram (DFD Level 0). It models Palermo as one
logical process and shows only data exchange with approved external entities.

External entities
-----------------
Business actors:
- Visitor
- Customer
- Administrator

External technical services:
- Email delivery service
- Stripe sandbox / payment service
- AI service / API

Boundary rules
--------------
- The internal simulated delivery provider is not an external entity and does not
  appear in the Level 0 context diagram.
- Supabase, PostgreSQL, Prisma and Next.js are implementation components, not
  external DFD entities.
- Raw card number/CVV data is not shown flowing into Palermo. Stripe handles card
  credentials through the provider-controlled payment interface; Palermo receives
  payment references/status and verifies provider results server-side.
- AI receives only minimised, purpose-specific approved context. Palermo remains
  authoritative for catalogue, stock, pricing, orders, delivery state and policy.
- No internal data stores are shown at Level 0. They are introduced in DFD Level 1.
